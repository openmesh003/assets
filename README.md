# OpenMesh model files

**Browse, preview and download these models at [openmesh3d.pages.dev](https://openmesh3d.pages.dev).**

This repository stores the raw files behind the OpenMesh website, a free archive of 3D models you can inspect in your browser before downloading. On the site you can rotate each model in 3D, check its details, and download it in the format you need.

## What's in this repository

| Path | Contents |
| --- | --- |
| `catalog.json` | The list of models the website shows. |
| `models/` | Model files. |
| `thumbnails/` | Preview images. |

The website reads these files directly from the `main` branch, so renaming or moving them can break the site.
